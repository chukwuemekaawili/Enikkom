## STYLE REFERENCE NOTES
### SLB Reference Video — Extracted Principles (Style Only)

| Principle | Observed Style |
|---|---|
| **Pacing** | Slow and deliberate — each shot held 3–6 seconds minimum. No panic cuts. Cinematic breathing room between ideas. |
| **Camera movement** | Smooth drone reveals, slow push-ins, gentle parallax pan. Never handheld shake. Motion serves gravity, not excitement. |
| **Tone & mood** | Premium industrial gravitas. Dark navy/steel surfaces. Warm amber work-light accents. Controlled, authoritative, trusted. |
| **Transitions** | Slow cross-dissolves and sound-bridged cuts. Hard cuts only when cutting across action within a scene. No jump cuts between moods. |
| **Color grade** | Desaturated midtones, crushed blacks, slight teal-orange complementary grade. Cinematic Rec.709 look. Blues and oranges separated. |
| **Typography** | Clean geometric sans-serif, white on dark. Wide letter-spacing. Minimal copy per card. Left-aligned or centered. Never decorative. |
| **Emotional rhythm** | Establish scale → introduce human expertise → demonstrate technical precision → reveal completion/result → affirm identity. |
| **Storytelling arc** | Challenge (hostile terrain) → People (Nigerian engineering expertise) → Process (technical mastery) → Proof (delivered infrastructure) → Brand (who we are, since 2003). |
